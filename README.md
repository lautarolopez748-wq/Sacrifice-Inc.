# Sacrifice Inc.

**Your body. Our business.** — Integrity Corp.

Dark Comedy / Puzzle Horror en Low Poly. Interpretas al **SUJETO #049**, capturado por un contrato engañoso de Integrity Corp., una corporación que convierte la experimentación humana en un procedimiento corporativo rutinario. Tu cuerpo es a la vez materia prima y herramienta: partes del cuerpo usadas estratégicamente para resolver puzles y avanzar por las instalaciones.

## Stack
- **Motor:** Unity 6 LTS + URP (Universal Render Pipeline)
- **Lenguaje:** C#
- **Modelado:** Blender 4.x LTS → Unity
- **Plataforma objetivo:** PC (gama baja/media)
- **Textos del juego:** Español

## Requisitos de desarrollo
- Unity 6 LTS (vía Unity Hub) con módulo *Windows Build Support*
- Blender 4.x LTS
- Git + Git LFS
- Hardware de desarrollo: el del equipo (Pentium G4560 / GTX 750 / 8 GB RAM) — escena pequeña y optimización desde el día 1

## Abrir el proyecto
1. Clonar el repo (o abrir `E:\Sacrifice Inc`).
2. Instalar/abrir Unity 6 LTS con Unity Hub y abrir esta carpeta.
3. Dejar que Unity resuelva los paquetes de `Packages/manifest.json`.
